# ChromeThemer

 ChromeThemer is an app that lets you directly modify the Material You (2) theme on Chrome. (as seen on images below)

Why not just download a theme from the web store? Well, themes to this day still do have access to the Material You colors they still use the same system from even before the Chrome refresh 2023 update. Also, ChromeThemer lets the average user edit themes on the fly.

Why not use chrome's default color picker? As you can see in the photos, not only are the colors much more vibrant, some of them are also multicolor

Is it safe? If you can read JavaScript, just read the code, and then you will be able to tell that its 100% safe. If you don't know JavaScript the best you can do is ask some sort of AI, but I have no idea how trustworthy that would be.

## ✨ Features

- Edit Material You colors
- Get Multi-Colored Themes
- Edit Themes on the fly
- No extensions needed
- Syncs to your google account

## 🚀 Getting Started

### Prerequisites

Make sure you are running this script on a supported Chromium-based browser.

### Installation

Go to ```chrome://customize-chrome-side-panel.top-chrome``` then press f12 then, go to the "console" tab and run the script there by pasting the script "ChromeThemer.js" on to the text box. ChromeThemer should then run.

It ran, what do I do now? Mainly, you will only need to use the first card (the seed one) expand it and you will see this: A color picker and a drop-down menu.

First, pick a color you like Next, in the drop-down choose one of these:

Neutral: Super muted, more muted colors then default

Tonal Spot: The default that chrome normally uses

Vibrant: The default, except crank the the vibrantness/saturation by 2x

Expressive: Vibrant but chrome will try its best to add in matching colors (is not perfectly accurate 100% of the time, sorry), leading to the multicolored themes u can see above

The rest of the options in the drop-down u can ignore, in ur case they don't matter
